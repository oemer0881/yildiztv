# YildizTV

TV-App für Android TV, Fire TV und Android-Geräte. Senderlisten laden, Sender in der Kachelansicht auswählen und mit der Fernbedienung einfach durchschalten. Es gibt eine eigene Version pro Sprache.

### Installation auf dem Fernseher
1. APK auf einen USB-Stick kopieren oder mit der App *Downloader* über den Link oben laden.
2. Installation aus unbekannten Quellen erlauben.
3. APK öffnen und installieren.

Die Versionen lassen sich gleichzeitig installieren. Neue Versionen meldet die App selbst, sie lassen sich direkt in der App laden und über die alte installieren.

## Funktionen
- Kachelansicht mit Senderlogos und Kanalnummern
- Kategorien, Suche, Favoriten und „Zuletzt gesehen“
- „Weiter“-Button für den letzten Sender
- Vollbild mit schnellem Umschalten
- Mehrere Senderlisten gleichzeitig, eigene M3U-Listen einstellbar
- Programmanzeige (Jetzt/Danach), wenn Programmdaten vorhanden sind
- Intro-Animation beim ersten Start
- Update-Hinweis in der App

## Bedienung

| Taste | Liste | Vollbild |
|---|---|---|
| OK | Sender starten | Sendername anzeigen |
| Lange OK | Favorit an/aus | – |
| Hoch / Runter | Auswählen | Sender wechseln |
| Kanal + / – | – | Sender wechseln |
| Links | – | Vorheriger Sender |
| 0–9 | – | Direkt zu Senderplatz springen |
| Menü | – | Favorit an/aus |
| Zurück | App beenden | Zurück zur Liste |

## Senderlisten
Standardmäßig lädt jede Version die öffentlichen Listen des jeweiligen Landes von [iptv-org](https://github.com/iptv-org/iptv). Unter **Senderlisten** kannst du eigene M3U-URLs eintragen.

Die App liefert selbst keine Sender mit. Für Inhalte, die du über eigene Listen abrufst, bist du selbst verantwortlich.
